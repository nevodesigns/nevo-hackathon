LogSight

An offline AI that turns messy notes, photos, and voice into a SIWES logbook a supervisor can sign. One local Gemma 4 model, no internet.

Runs on device gemma4:e4b No network No accounts

01 / The problem

The logbook gets written from memory, the night before.

Every Nigerian undergraduate on SIWES has to keep a daily logbook. It is signed by an industrial supervisor and it counts toward the grade. Almost nobody fills it in daily, so weeks of it get reconstructed from memory when a supervisor visit is announced.

The obvious fix, an AI writing assistant, does not survive contact with the placement. Students are posted to workshops, factories, farms and rural sites where the network is unreliable and mobile data is a real cost. A tool that needs the cloud is not there on the day the logbook is due.

02 / How it works

Three ways in, one local model, nothing uploaded.

Capture the day however suits the moment. Every route meets the same pipeline and the same guards, so a photo earns no more trust than typed text.

01

Text

Type or paste shorthand. A week written as one run on paragraph is split into a separate entry per day.

02

Photo

Photograph a handwritten page. Gemma 4 reads the handwriting natively on your machine, with no separate OCR engine.

03

Voice

Speak the day in English or Pidgin. The same model transcribes the audio locally, and you see the transcript before anything is generated.

03 / The engineering

It formats what you did. It never invents what you did not.

A logbook is signed by a supervisor who was actually there. If it claims you calibrated a sensor you never touched, you are asking someone to put their name to a false record. Fabrication is the one failure this project treats as unacceptable, ahead of speed and polish. An honest thin entry is a good outcome. A fluent invented one is a defect.

  • Two stage pipeline

    Strict extraction pulls only what is present. A separate pass rewrites those facts into formal English, never seeing the original notes, so it has nothing extra to add.

  • Nothing is guessed

    Any field the notes do not state is marked not specified rather than filled in. No invented dates, supervisors, tools or concepts.

  • Involvement kept

    Work you did stays work you did. Helped weld the frame is never quietly downgraded into observed the welding.

  • No edit path

    A saved entry stands exactly as produced, or it is deleted. Editing would let text be rewritten after every guard had already run.
