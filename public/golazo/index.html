The 2026 FIFA World Cup ended on 19 July 2026. Nobody built agent-payable infrastructure for the finished tournament, because live data providers moved on the moment the final whistle blew. SHT 03 / THE FOUR INJECTIVE TECHNOLOGIES

Every claim below maps to a file in the repository. The code is pulled verbatim from it.

TECH-01x402

Payment protocol

HTTP 402 micropayments in USDC, settled with EIP-3009 transferWithAuthorization. No per-call approval, and the facilitator pays the gas.

Here it gates every premium route. The client receives the 402, signs, and retries automatically.

// receive 402, sign EIP-3009, retry, no human
import { createInjectiveClient } from
  "@injectivelabs/x402/client";

const client = createInjectiveClient({
  privateKey: process.env.GOLAZO_WALLET_KEY,
});
const res = await client.fetch(API + "/v1/premium/stats");
const data = await res.json();

TECH-02MCP SERVER

Agent access

A Model Context Protocol server over stdio, exposing seven tools. Premium tools auto-pay through the x402 client, so an agent buys data with no human in the loop.

Add one config block to Claude Desktop, Cursor, or any MCP client.

{
  "mcpServers": {
    "golazo": {
      "command": "npm",
      "args": ["run", "mcp"],
      "env": {
        "GOLAZO_API_URL": "http://localhost:3000",
        "GOLAZO_WALLET_KEY": "0xYOUR_AGENT_KEY"
      }
    }
  }
}

TECH-04CCTP

Cross-chain funding

Circle CCTP V2 lets the agent refuel its own USDC. It burns native USDC on Avalanche Fuji and mints it to the agent on Injective, domain 29.

One command runs burn, attest, and mint.

# burn on Fuji, Iris attests, mint on Injective
GOLAZO_WALLET_KEY=0x<agent> \
PRIVATE_KEY=0x<facilitator> \
  npm run fund-agent -- 0.5

SHT 05 / ARCHITECTURE

FLOW-01PAY AND RETURN
  1. Client agent calls a premium tool through the MCP server.
  2. The x402 middleware returns 402 with EIP-3009 payment terms.
  3. The client signs and retries with the payment header.
  4. A custom facilitator confirms settlement via eth_getLogs, not eth_getTransactionReceipt, which does not work on this testnet.
  5. The tool returns the data.

TESTNET RPC FINDING

Injective testnet emits transfer logs but returns null for eth_getTransactionReceipt on the same transaction, tested across four RPC endpoints. That is why settlement is confirmed with eth_getLogs.

SHT 07 / DATASET INTEGRITY

The offline seed contains all 104 matches, all 48 teams, and all 12 groups, so the API is complete with no network access and no key. The final was Spain 1 Argentina 0 on 19 July 2026, Ferran Torres 106th minute, at MetLife Stadium.

The dataset was reconciled against football-data.org's authoritative feed, and the reconciliation caught a real error in an early seed, a Norway vs Brazil scoreline. Every match carries a provenance field, verified or imported. The refresh script keeps both paths working.
